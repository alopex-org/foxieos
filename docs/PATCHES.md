# FoxieOS patches

A patch, here, is a change FoxieOS makes to the software it builds on (roadmap decision D10), instead of adding a file of its own.
FoxieOS has to re-apply each one whenever that software updates, so they are kept few and all listed here ([CONTRIBUTING.md](../CONTRIBUTING.md#changes-to-the-base-system)).

At every move to a new major version of the base, review the whole list, and drop any patch that the upstream project has accepted into its own code.

**Status: none yet.**

The columns: the package or file; the commit or change; why FoxieOS needs it; whether the upstream project has accepted it; when it was added; and when it was last checked.
